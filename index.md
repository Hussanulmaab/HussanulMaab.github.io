# Intro

<!--author-->

I'm a master's researcher in the Department of Electronics and Information
Convergence Engineering at **Kyung Hee University**, in the group of
Prof. Hyundong Shin.

My work sits in **quantum error correction**. My thesis develops tensor
network decoders for **three-dimensional color codes** — using tensor network
contraction to approximate maximum-likelihood decoding on a code family whose
3D structure makes the usual matching-based decoders awkward to apply.
Code for that work lives in
[TNDecoder3DColor](https://github.com/Hussanulmaab/TNDecoder3DColor).

More broadly I'm interested in code constructions and decoder design: what
makes a code practical to decode, and how far approximate contraction can be
pushed before the accuracy is gone.

Outside the research I occasionally write [interactive posts](/blog/) about
things I want to understand better, and I tutor on the side.

on [GitHub](https://github.com/Hussanulmaab). My CV is [here](/cv/).
